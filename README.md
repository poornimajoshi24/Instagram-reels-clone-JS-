# Instagram Reels Clone (Vanilla JavaScript)

A **frontend Instagram Reels–style short video feed** built using **Vanilla JavaScript**, focusing on **data-driven UI rendering, state management, and event delegation** without any frameworks.

This project simulates core social-media interactions such as **likes, follow/unfollow, mute/unmute, and dynamic counters**, similar to real-world short-video platforms.

---

## 🚀 Features

* 🎥 Auto-playing short video reels
* ❤️ Like / Unlike with live counter update
* 🔔 Mute / Unmute video sound
* ➕ Follow / Unfollow users
* 🧠 Centralized state management using JavaScript objects
* ⚡ Event delegation for efficient event handling
* 🔁 Dynamic DOM re-rendering based on state changes

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3 / SCSS** – Styling & layout
* **Vanilla JavaScript** – Logic, state management, and DOM manipulation

> No frameworks or libraries were used. This project demonstrates core JavaScript fundamentals.
